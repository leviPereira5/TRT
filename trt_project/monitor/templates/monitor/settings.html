Como configurar o envio de emails (Gmail)

O sistema usa SMTP para enviar alertas. Para o Gmail, segue estes passos:

  1. Ativa a Verificação em 2 passos na tua conta Google.
  2. Em Segurança → Passwords de aplicações, cria uma nova password para "TRT Invest".
  3. No ficheiro .env do projeto, preenche:
    EMAIL_HOST_USER=o-teu@gmail.com EMAIL_HOST_PASSWORD=xxxx xxxx xxxx xxxx
  4. Reinicia o servidor Django depois de guardar o .env.
